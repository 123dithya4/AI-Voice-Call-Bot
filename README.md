# AI Voice Call Bot

An AI-powered voice calling application built using Vapi and Twilio.
It allows users to make AI voice calls using a web-based dashboard.

## How It Works

User enters a phone number and call instructions →  
Backend sends the request to Vapi →  
Vapi uses the configured voice assistant →  
Twilio handles the phone call →  
Call information is stored and displayed in the dashboard.

## Features

- AI-powered voice calls
- Custom call instructions
- Call history
- Call status tracking
- Recordings and transcripts
- Dashboard for monitoring calls
